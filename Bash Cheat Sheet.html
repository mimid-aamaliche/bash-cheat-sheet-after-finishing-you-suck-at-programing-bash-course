Bash Cheat Sheet

Reference notes from Dave Eddy's free "You Suck at Programming" Bash course — organized by topic, not by timestamp.

1 · Terminal basics navigation

pwd                  # print working directory
ls -la               # -a hidden, -l long listing
cd dir / cd .. / cd - / cd
touch file           # create / update timestamp
rm file              # PERMANENT — no trash. rm -i to confirm
mv old new           # silently overwrites existing dest!
cp src dst
mkdir name

Shell = REPL (read → eval → print → loop). . = current dir, .. = parent, both built into every dir.

2 · Basic globbing

*zero or more chars
?exactly one char
[abc]one of a/b/c

Quote patterns before passing to a program: find . -name "*.txt"

3 · Redirection & pipes

syntaxmeaning
cmd > filestdout → file (overwrite)
cmd >> filestdout → file (append)
cmd < filefile → stdin
cmd1 | cmd2pipe stdout → stdin
cmd 2> filestderr → file only
cmd > f 2>&1both → same file (order matters!)
cmd 2>&1 >fstderr→screen, stdout→file

fd 0=stdin, 1=stdout, 2=stderr. 2>&1 means "point fd2 at whatever fd1 points to right now" — a snapshot, not a live link.

4 · Search / pager / docs

grep -i -o -c -A2 -B2 -C2 pattern file
less file            # j/k move, /pat search, n/N next/prev, q quit
man cmd               # man 3 printf = library section
help cmd                # docs for bash BUILTINS (man won't show these)
type -a cmd               # builtin/alias/external + search order — use over `which`
compgen -b                  # list all builtins

5 · Variables

name=Dave              # no spaces around =
echo "$name"             # ALWAYS double-quote expansions
unset name
thing=$(uname -a)          # command substitution — preferred
thing=`uname -a`             # legacy backtick — avoid, hard to nest

Built-ins: $PATH $PWD $USER $HOSTNAME $RANDOM $SECONDS $EPOCHSECONDS. Bash 5.3+: ${ cmd; } runs in current shell (vs $(...) which forks a subshell).

6 · Making scripts

#!/usr/bin/env bash
chmod +x script && ./script
bash -n script        # syntax check only, no execution
bash -x script           # debug: prints every command run
bash -u script              # error on unset variables
set -x / set +x                # toggle tracing mid-script

shellcheck (external tool) statically lints scripts — use it.

7 · Taking input

read -rp "Name: " name    # -r = don't mangle backslashes
echo "$1" "$#" "$@"        # arg1, argc, ALL args (quote "$@"!)
[[ -n "$1" ]]                # true if $1 is set/non-empty

8 · Conditionals

if [[ cond ]]; then ...
elif [[ cond ]]; then ...
else ...
fi
== !=string compare
-f -d -e -s -Lfile / dir / exists / non-empty / symlink

Prefer [[ ]] (bash keyword, safe unquoted) over [ ]/test (external-ish, quote everything). while/until [[ cond ]] loops too. Any command works as a condition — checks its exit code.

9 · Loops

for x in foo bar baz; do echo "$x"; done
for x in "$@"; do ...; done          # loop script args, quoted!
for i in {1..5}; do ...; done          # brace range, {1..10..2} step
for ((i=0;i<10;i++)); do ...; done       # C-style — needed for variable limits
while read -r line; do ...; done < file    # line by line, no subshell

continue / break as usual.

10 · Functions

greet() {
  local name=$1     # ALWAYS `local` — avoids global leaks
  echo "hello $name"
}
var=$(greet Dave)      # capture output — runs in subshell
return N                  # sets exit code, function-only ($? after)

11 · Case statements

case "$var" in
  pat1) cmd ;;
  pat2|pat3) cmd ;;     # | = OR
  *) default ;;
esac

;; stop at match · ;& fall through · ;;& keep testing more patterns.

12 · Arrays

arr=(foo bar baz)
"${arr[0]}"   "${arr[-1]}"     # index (curlies required), negative works
"${arr[@]}"                       # ALL elements — always quote + use @ to loop
"${arr[*]}"                          # ALL joined into one string (by $IFS) — for stringifying only
"${#arr[@]}"                            # length (count)
arr+=(more items)                          # append
new=("${arr[@]}" extra)                       # copy/extend
declare -A map; map[foo]=1                       # associative array, capital -A
for k in "${!map[@]}"; do echo "$k ${map[$k]}"; done  # ! = keys

13 · Parameter expansion (avoid forking external tools)

${#s}                  # length          ${s^} / ${s^^}      # capitalize first / all
${s,} / ${s,,}            # lowercase first / all
${s:-default}                # use s, else default (doesn't assign)
${s:=default}                   # same, but assigns default to s
${s:?msg}                          # error out if unset/empty — required-arg pattern
${s:offset:len}                       # substring
${s/find/repl}   ${s//find/repl}         # replace first / all
${s#pat} ${s##pat}                          # strip shortest/longest match from FRONT
${s%pat} ${s%%pat}                             # strip shortest/longest match from END (##/%% = greedy)
${path##*/}  ${path%/*}                           # poor-man's basename / dirname

Same slicing/replace syntax works on arrays: "${arr[@]/find/repl}"

14 · Command / process substitution

$(command)      # capture stdout as string
<(command)         # treat output AS A FILE — avoids the pipe-subshell var-loss gotcha
# classic bug: piping into `while` runs in a subshell, so counters vanish after
grep d f | while read -r w; do ((i++)); done   # $i lost!
while read -r w; do ((i++)); done < <(grep d f) # $i correct

15 · Arithmetic

$((expr))            # expansion — no $ needed on vars inside
((expr))                # command form; false if result is 0!
((a>b?a:b))                # ternary works

Leading zero = octal (08 errors!). Force base: 10#$var, 16#FF. Use (( a > b )) for numbers — [[ $a > $b ]] is a string compare.

16 · Sourcing / subshells

source file.sh    # same as: . file.sh
( cmds )             # subshell — vars don't leak out
{ cmds; }               # current shell — needs trailing ; and space
if ! (return 0 2>/dev/null); then main "$@"; fi  # run-if-not-sourced guard

17 · Exit codes & pipelines

$?                     # exit code of last command
"${PIPESTATUS[@]}"        # exit code of EVERY stage in last pipeline (grab immediately!)
time cmd                    # real/user/sys — it's a keyword, so `sudo time x` fails

In a | b | c, plain $? only reflects c.

18 · External text tools

tr 'a' 'b'translate characters
cut -d, -f1,3fields by delimiter
sed 's/old/new/g'find/replace stream editor
awk -F: '{print $1}'field-based text mini-language
sort | uniq -cdedupe + frequency count
wc -l/-w/-clines/words/bytes
find . -type f -name "*.txt"find files, -exec cmd {} \;
xargsbatch args from stdin

19 · shopt / extended glob

while IFS=: read -r name pass uid; do ...; done < /etc/passwd  # delimited parsing, no cut needed
shopt -s extglob    # !(x) neg · +(x) 1+ · @(x) exactly-1 · *(x) 0+ · ?(x) 0-1
shopt -s nullglob      # unmatched glob → nothing, not literal string
shopt -s dotglob          # globs match dotfiles too
shopt -s globstar            # ** recurses subdirectories

20 · Brace expansion

file.{txt,jpg,mov}    # → 3 strings (NOT filesystem-aware, unlike globs)
{1..20}  {1..20..5}  {10..1}   # range, step, auto countdown

No variables in ranges — {1..$max} fails; use a C-style for loop instead.

21 · printf

printf '%s\n' "$var"     # NEVER printf "$var" raw — it's a format string
printf '%5s\n' hi           # right-pad to width 5
printf '%-5s\n' hi             # left-justify
printf '%05d\n' 7                 # zero-pad number
printf -v var '%s' val               # store into a variable
printf '%q\n' "$var"                    # shell-safely quote a string
printf '%(%F %T)T\n' -1                    # current date/time, builtin (no `date` fork)

22 · Regex & mapfile

re='^(Dave|Joe)$'
[[ "$x" =~ $re ]] && echo "${BASH_REMATCH[0]}"   # [0]=whole, [1]=group1…
mapfile -t arr < file      # read file into array, -t trims newlines

23 · test vs [ ] vs [[ ]]

test / [ — legacy, both builtin & external binary, quote everything. [[ ]] — bash keyword, better parsing, glob/regex aware. Always prefer [[ ]] in bash.

24 · ANSI colors & prompt

printf '\e[1mBOLD\e[0m\n'                 # \e=ESC · 1=bold 0=reset
printf '\e[31mred\e[0m\n'                    # 30-37 fg (0blk 1red 2grn 3ylw 4blu 5mag 6cyn 7wht), 40-47 bg
printf '\e[38;5;196mC256\e[0m\n'                # 256-color mode
printf '\e[38;2;255;0;0mRGB\e[0m\n'                # 24-bit true color
tput bold; tput setaf 1; tput sgr0                   # portable-ish; tput reset if terminal breaks
[[ -t 1 ]]                                              # is stdout a terminal? — auto-disable color when piped
PS1='...\[\e[32m\]\u@\h\[\e[0m\] \w\$ '                    # wrap color codes in \[ \] or cursor math breaks!

25 · ~/.bashrc essentials

[[ -z "$PS1" ]] && return    # bail if non-interactive
alias ll='ls -lh'
shopt -s cdspell autocd extglob

26 · Signals & jobs

trap cleanup EXIT        # run on script exit
trap 'echo hi' SIGINT       # respond to Ctrl+C
trap -l                        # list all signals
jobs · fg · bg · kill %1          # manage background jobs (Ctrl+Z suspends)

SIGKILL (kill -9) can never be trapped.

27 · Named pipes

mkfifo pipe
echo hi > pipe      # blocks until read
exec 3<> pipe          # persistent fd; read -u 3 line

⚠ Big gotchas

  • Never loop over $(ls ...) — breaks on spaces/newlines in filenames. Use globs or find -print0 | xargs -0.
  • Aliases can't take arguments the way you'd expect — use a function.
  • Colored strings have invisible escape bytes — ${#str} counts them too.
  • Fork bomb :(){ :|:& };: — recursive exponential forking. Never run it. Know it to avoid it.
  • Quote all expansions: "$var", "${arr[@]}" — except plain x=$y assignment.
  • Exit codes wrap at 256 — exit 256 looks like success(0).
  • $? in a pipeline only reflects the last stage — use PIPESTATUS.
